# LOCATION-TRACKER---JAGGUS-TRACKER
What it does:  - Generate tracking links (custom or random slug) with QR codes - Capture RAW GPS lat/lng, IP, UA, device info when victims open the link - Live OSM map with GPS accuracy circles, amber/red GRANTED/DENIED pins - Sortable tracking log with reverse-geocoded addresses + 1-click Google Maps nav - Stats cards: hits, unique device
